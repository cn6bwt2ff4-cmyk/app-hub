# 我的工作台

一个纯前端的移动端 App 工作台，浏览器打开即用，也可以添加到手机主屏幕像原生 App 一样使用。

## 功能

| Tab | 功能 |
|-----|------|
| 首页 | 问候语、天气、快捷入口、待办/笔记预览 |
| 待办 | 增删改查、完成标记、筛选（全部/未完成/已完成） |
| 笔记 | 写笔记、编辑、删除，底部弹层编辑 |
| 工具 | 计算器、单位换算、二维码生成、取色器、日期计算、密码生成 |
| 我的 | 昵称设置、数据统计、数据导入/导出、清空 |

## 特点

- **纯前端**：HTML + CSS + JS，无后端，无依赖
- **数据本地存储**：所有数据存在浏览器 `localStorage`，不会上传
- **移动端优先**：适配 iOS/Android，支持添加到主屏幕全屏使用
- **可离线**：加载后基本可离线使用（天气、二维码生成需联网）

## 使用

### 方式一：直接打开
用浏览器打开 `index.html` 即可。

### 方式二：添加到手机主屏幕（推荐）
1. 把 `index-hub` 目录部署到任意静态服务器（或传到 GitHub Pages / Vercel / Netlify）
2. 在 iPhone Safari 或 Android Chrome 打开
3. 分享 → 添加到主屏幕
4. 之后从桌面图标进入，全屏体验，像原生 App

### 方式三：本地预览
```bash
cd app-hub
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 自定义

想改成自己的样子？看这里：

| 想改什么 | 改哪里 |
|---------|--------|
| 主题色 | `styles.css` 顶部 `:root` 里的 `--primary` |
| Tab 数量/图标 | `index.html` 的 `.tabbar` 部分，并在 `app.js` 的 `tabs` 数组和 `renderPage` 里同步 |
| 工具卡片 | `app.js` 的 `renderTools` 函数 |
| 首页布局 | `app.js` 的 `renderHome` 函数 |
| 初始示例数据 | `app.js` 最底部的首次初始化代码 |

## 技术栈

- 原生 HTML5 / CSS3 / JavaScript（无框架）
- localStorage 持久化
- 响应式 + 安全区适配（`safe-area-inset`）
- 适合作为后续扩展的骨架：要加后端、加账号、加更多 Tab 都很方便
